# Business Proposal — evidence and source mapping

Companion to `R2_BUSINESS_PROPOSAL.md`. Every claim of consequence in the
proposal appears below with its classification and the artefact that supports
it, so any statement can be checked without reading the codebase.

| Class | Meaning |
|---|---|
| **[M] MEASURED** | Observed by running this system. Reproducible from the repository. |
| **[S] SYNTHETIC_EVALUATION** | Real measurement on a dataset this repository generates, whose ground truth it knows by construction. |
| **[R] RESEARCH_SOURCED** | External published finding. Not our result. |
| **[A] ASSUMPTION** | A stated assumption. Not derived from data. |
| **[I] ILLUSTRATIVE** | A worked example. Directionally meaningful, numerically arbitrary. |

## 3. Synthetic evaluation claims [S]

> Dataset: seed `20260821`, 535 days, 6 injected events, generated by
> `data/generate.py`. Ground truth known by construction.

| Claim | Value | Artefact | Stated limitation |
|---|---|---|---|
| Detection precision | 1.000 | `eval/detection_report.md` | Over *injected* events |
| Detection recall | 1.000 | same | Events built to be detectable by this method's assumptions |
| Detection false positives | 0 of 48 clean slices | same | **The meaningful figure** — not guaranteed by construction |
| Ranking robustness | 100% of 300 resamples | `eval/attribution_report.md` | Resampling the same series, not out-of-sample |
| Retrieval BM25 p@5 / recall@10 | 0.552 / 0.654 | `eval/retrieval_report.md` | Post-realism-audit |
| Retrieval dense recall@10 | 0.778 | same | Beats BM25 — first measured justification for hybrid |
| Retrieval RRF MRR | 0.838 | same | Best MRR of the three |
| Gate 2 false acceptance | 0 of 10 | `eval/verification_report.md` | None of *those* got through — not that none could |
| Gate 2 false rejection | 0 of 6 | same | |
| Injected violations caught | 9 / 9 | same | |
| Calibration HIGH | 12 of 12 | `eval/recommendation_report.md` | Synthetic; MEDIUM/LOW report `UNCALIBRATED` |

**Superseded figures — deliberately not quoted as current:** BM25 p@5 0.810 /
recall@10 0.957, dense recall@10 0.933, RRF MRR 0.964. These were measured on a
corpus holding only 13 distinct document texts across 895 records. The realism
audit widened it, every score fell, and the lower numbers are the ones
reported. See `eval/data_realism_audit.md`.

## 9. Open evidence gaps

Stated so a judge finds them here rather than by cross-examination:

| Gap | Consequence | What would close it |
|---|---|---|
| **No live LLM evaluation** | Model latency, tokens, cost, first-pass verification rate unmeasured | An API key; `eval/run_llm_eval.py` is implemented |
| **No real-data validation** | Every metric is synthetic | One historical incident from a willing organisation |
| **No baseline time-to-explanation** | No value claim can be quantified | Measure current investigation time in a pilot |
| **Feedback loop never run** | "Learns from feedback" is a capability, not a result | One quarter of real analyst decisions |
| **Only HIGH band calibrated** | MEDIUM/LOW report `UNCALIBRATED` | ≥10 observed cases per band |
| **No authentication** | Authorisation is real; identity is not | Enterprise IAM |
| **No concurrency testing** | Capacity is reasoned, not measured | Load test after the storage migration |
